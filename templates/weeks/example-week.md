# Wnn · <dates> · <phase>

Example file — real weeks (`weeks/20*`) are gitignored.

Target **~NN km**. Purpose: one line on what this week is for.

The **Session** column repeats the `.yaml` workout name verbatim, so this table, the
calendar and the watch all say the same thing. Everything the name leaves out — gym,
fuelling, whether a run is droppable — belongs in **Detail**, not in the name.

**Role** repeats the `.yaml` `role:` — what each session is *for*, which the name can't
carry. It's here so the week is reviewable at a glance: count the `key` rows against the
ceiling, check no two sit back to back, see that Wednesday's club night is `social` rather
than the `easy` its name implies. Wrong here means wrong on the calendar.
